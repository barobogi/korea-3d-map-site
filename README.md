# 대한민국 3D 지도 (비공개 베타)

시군구를 눌러 입체 지도로 들어가는 오픈 지도 서비스입니다. 현재 **종로구 랜드마크 블록 51개**(선택해서 보기, 상세 품질 검증 진행 중)만 열려 있고, 나머지 시군구는 검증을 마친 곳부터 순차 공개합니다.

- 상태: **비공개 베타(L1)**. 검색 엔진 노출 차단(noindex), 홍보 전.
- 구조: `index.html`(전국 첫 화면) → `b/{시군구코드}/`(동네 지도) → 랜드마크 카드.
- 읽기·탐색은 로그인 없이 가능. 회원·게시판은 이후 단계(S1).
- 오류 신고: Issues > 오류 신고 양식.
- 출처·라이선스: [ATTRIBUTION.md](ATTRIBUTION.md)
- 개인정보: [PRIVACY.md](PRIVACY.md) (초안)
- 기여: [CONTRIBUTING.md](CONTRIBUTING.md)

저장소에는 실행 비밀값·개인 위치·사진 데이터를 올리지 않습니다.


> 공개 배포본: 고정밀(LOD3) 원본은 포함하지 않습니다(저가 LOD2만).
