# 127 HMYS 전체 구조 마스터 (만복, 2026-11-09)

목적: 만복이 지도(HMYS) 전체 구조를 한 장으로 소유하고, 안티·제미나이·피망/피클에게 같은 기준으로 지시한다. 충돌 시 이 문서가 우선이다(118·124·125·126은 세부 설계).
상태 표기: ✅ 검증 완료(증거 있음) / 🟡 부분(일부만 증거) / ⬜ 미착수 / ⛔ 막힘.

## 0. 한 문장
내 동네(종로)를 열면 3초 안에 실제 모양의 3D 블록이 보이고, 출처와 확인일이 함께 있으며, 블록마다 저장·공유·길찾기로 끝난다. 종로를 완성한 뒤 같은 기준으로 구를 늘린다.

## 1. 원칙 (위반 시 반려)
1. 품질 증명은 육안 캡처다. 파일 수·삼각형·해시 통과는 "통과"가 아니다.
2. 완료 주장은 증거 경로가 있어야 한다(캡처, 커밋 SHA, 실측값). 증거 없는 "완료"는 미완료다.
3. 블록마다 손으로 높이·위치를 맞추지 않는다(규약 117: 원점 y=0, 지형은 로더가 한 번만 가산).
4. 같은 틀·같은 텍스처·같은 소품을 여러 블록에 반복하지 않는다.
5. 출처·확인일이 없는 값은 "확인 필요"로 표시하고 추정치를 쓰지 않는다.
6. 개인 위치·이동·사진 원문은 외부(공개 저장소, 쓰레드, 데모)에 올리지 않는다. 개발·개인 기기 내 사용은 허용.
7. 원본(LOD3·텍스처)은 비공개 저장소에만 둔다. 공개 배포본은 빌드 스크립트로 LOD2만 낸다.
8. 실행 코드(.py 등)는 외부 생성물에 없어야 한다. 데이터 4종(manifest, lod2, lod3, texture)만 받는다.

## 5. 블록 파이프라인 (생산 → 판정 → 반영)
1. 발주: 만복이 구별 발주서를 작성, 블록 번호는 실제 폴더 이름 기준(혼동 방지).
2. 제작: 피망·피클. 제출 4종 + 출처(reference_url, official_height_m, verified_at). 출처 없으면 null.
3. 격리: 만복이 PR 데이터를 quarantine에 받는다. 실행 파일 있으면 반려.
4. 판정: 만복이 블록별 3D 캡처 → 구별 모아보기(sheet). 판정 기준 아래 §6.
5. 반영: 통과분만 비공개 저장소에 넣고 전수 캡처(51/N) 회귀 확인 → 공개 배포(승인 후).
6. 기록: 점검표 갱신, 결함 대장에 번호·재현·캡처 경로.

판정 기준(블록별): ① 그 건물을 화면만 보고 알아볼 수 있는가 ② 같은 틀 반복이 아닌가 ③ 지면에 붙어 있는가(공중부양·땅속 없음) ④ 텍스처 깨짐이나 부품 분리가 없는가 ⑤ 출처·확인일이 있는가. 5개 중 ①②③④ 필수, ⑤는 공개 전 필수.
