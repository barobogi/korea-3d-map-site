솔직한 상태: 기능 흐름(전국→동네→블록→카드, 회원·참여 단계)은 124·125호로 설계했지만, **사람을 붙잡는 장치(첫인상·재미·재방문·공유)는 설계가 비어 있었음.** 이 문서가 그 빈칸.

## 0. 원칙
- 관심 장치는 **지도 품질 위에서만** 의미 있다. 블록이 엉성하면 장치가 오히려 실망을 키운다 → 품질 게이트 통과 동네만 장치를 켠다.
- 개인 위치·사진은 기기 안에서만. 관심 측정은 개인 식별 없이 블록 단위 집계.
- 모든 장치는 통과/전체 분수로 채점(아래 §4).

## 3-1. 바로보기님 분석 자료 반영 (3AI_map, 11/09 00:36)

2. **상황별 필터**(자료① 8장): 혼자 산책 / 데이트 / 가족 / 비 오는 날 / 야경 — 블록마다 해당 상황 태그.
3. **모든 카드는 저장·공유·길찾기 중 하나로 끝난다**(자료① 8장): 도장(저장) + 공유 카드 + 외부 지도 앱 길찾기 링크.
4. **허브-스포크**(자료① 7장): 홈페이지가 허브, 유튜브·쓰레드는 해당 장면 딥링크로 돌아오게(L2 공개 후).
5. **AI가 인용하는 페이지(GEO)**(자료① 6장): 블록 카드에 위치·운영시간·출처·확인일을 같은 형식으로 + 장소 구조화 데이터. 지금은 비공개 베타(noindex)라 L2 공개 때 켬.
6. **데이터 신뢰 표시**(자료② 8장): 확인 안 된 정보는 비우지 말고 '확인 필요'로 표시, 확인일 항상 노출.
7. **역할 분리**(자료② 9장): 홈페이지=검색 유입·신뢰 허브, 모바일=걸으며 쓰는 핵심 행동·재방문.
8. **KPI**(자료①12장·②16장): 조회수 대신 저장·공유·재방문, 블록 열람→길찾기 전환.
9. **수익화는 신뢰 뒤에**(자료① 15·16장, ② 13장): 품질·재방문 검증 전엔 광고 없음. 이후 순서: 지자체·관광 B2B 3D 큐레이션 지도 → 제휴(예약) 고지 → 굿즈·멤버십. 지도 데이터 라이선스(OSM ODbL·공공누리) 상업 이용 범위 확인이 선행.
10. **쓰레드 포맷**(자료① 10장, L2 이후): 한 줄 훅 → 지도 링크 → 추천 3곳 → 질문 → 다음 편 예고.
